Usando o teclado para navegar pela interface do Google Planilhas

Aprender a navegar pela interface do Google Planilhas usando apenas o teclado é uma habilidade excelente para aumentar a produtividade e garantir acessibilidade no uso do aplicativo sem a dependência do mouse.

Como abrir o Google Planilhas usando apenas o teclado:

Se você estiver na Área de Trabalho do Windows, siga estes passos:

  1. Pressione a tecla para abrir o menu iniciar.
  2. Digite o nome do seu navegador de internet (ex: chrome ou edge) e pressione enter.
  3. Na barra de endereços que se abrir, digite: sheets.new e pressione enter. Uma planilha novinha em folha surgirá na tela de forma instantânea!

Atalhos de acesso às barras de ferramentas

No ambiente web, os navegadores às vezes disputam os atalhos com as páginas. Por isso, os comandos do Google Planilhas usam combinações específicas. Teste os comandos a seguir:

  • Tecla alt: Para abrir os menus superiores sem mouse no Windows, pressione alt. Observe que cada opção da barra de menus terá uma das letras sublinhadas. Pressione a letra sublinhada para navegar entre as opções.
  • Teclas de setas: Permitem que você navegue dentro das opções da Barra de menus após ativá-lo pela tecla alt, ou mude de célula dentro da área de trabalho da planilha.
  • Tecla enter: Entra no modo de edição da célula selecionada, posicionando o cursor para você digitar ou alterar os dados.
  • Tecla esc: Cancela a edição atual na célula ou fecha qualquer menu suspenso que tenha sido aberto por engano, devolvendo o foco para a grade.
  • Navegação em abas inferiores: Quando estiver com uma das Guias de Planilhas (abas inferiores) selecionada, use a combinação alt + ou alt + para abrir o menu de opções daquela aba ou alternar entre as páginas.
